# Leaf Disease Detection 🌿

## About the Project
Leaf Disease Detection is an Android application that helps detect plant leaf diseases using image classification.

## Technologies Used
- Android Studio
- Kotlin
- TensorFlow Lite
- Machine Learning

## Features
- Select or capture a leaf image
- Analyze the leaf image
- Predict the disease using a machine learning model
- Simple and user-friendly Android interface

## How It Works
1. Open the application.
2. Select or capture a leaf image.
3. The image is processed by the TensorFlow Lite model.
4. The application displays the predicted disease.
